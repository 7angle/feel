# Contributing

1. Read and agree to [CLA.md](CLA.md). Add this line to Your first pull request: `I have read CLA.md and I agree to it.` 7 Angle cannot merge a pull request without it.
2. Do not commit videos. Do not commit projects made from copyrighted media.
3. Keep logic in `Packages/FeelCore`. Keep the UI thin.
4. Run `swift test` in `Packages/FeelCore` before you open a pull request.
5. Keep each pull request small and on one subject.

Why the CLA: 7 Angle ships the apps in app stores. App store terms and the AGPL do not always agree. The CLA lets 7 Angle ship all Contributions in the stores.
